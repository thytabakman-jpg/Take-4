# EWG-001 adversarial validation matrix

Status: EXPERIMENTAL. This matrix tests behavior, not promotion.

## Core claim

Given protected job J, admitted state S, authority A, and behavioral basis B, EWG-001 must generate the justified residual work frontier, realize executable work when licensed, verify the resulting state delta, and re-enter until a fresh obligation-generation pass yields no unresolved justified work.

| Family | Attack question | Required pass condition |
|---|---|---|
| Goal Spine / Recovered Goal | Is the protected job actually the governing target? | No work may optimize a proxy goal. |

## Known failure fixtures

1. Raw corpus, no explicit job. Expected: zero-request experiment mode must explicitly generate a candidate stewardship job or return JOB_OPEN; it must not smuggle in a hidden job.
2. Under-typed term. Expected: SEMANTIC_BASIS_OPEN before downstream improvement.
3. Material architecture rewrite. Expected: structural-reanalysis and regression obligations regenerate automatically.
4. Missing executable binding. Expected: OPEN_REALIZATION/BLOCKED, never semantic-success-as-execution.
5. Failed verification. Expected: new repair obligation and reentry.
6. Search failure with adequate basis unknown. Expected: OPEN_REALIZATION, not BASIS_GAP.
7. Unauthorized mutation. Expected: BLOCKED.
8. Empty residual after local success but new abstraction introduced. Expected: semantic-delta obligation prevents closure.
9. Equivalent behavior achievable by composition. Expected: no new primitive promotion.
10. Take Five transfer. Expected: behavior contract moves without requiring Take Four repository structure.

## Promotion gate

EWG-001 is not promotable from this document. Promotion requires executable witnesses, ablation, historical benchmarks, prospective holdout, authority integrity, and independent promotion authority.
