## Joint n-ary finding

The strongest common candidate object is not a collection of maps. It is a job-indexed controlled transition system with admissible continuations.

Let:
- Z be typed system/history states;
- J be a protected job/evaluation context;
- A_J(z) be admissible controller actions at z;
- z --a--> z' be licensed transitions;
- Obs_J be the protected observation/evaluation map;
- Cont_J(z) be the set of admissible future continuations from z.

Candidate behavioral relation:

z1 ~=_J z2
iff
their J-relevant admissible continuation behavior is observationally indistinguishable.

One extensional candidate is:

z1 ~=_J z2
iff
{ Obs_J(kappa) : kappa in Cont_J(z1) }
=
{ Obs_J(kappa) : kappa in Cont_J(z2) }.

This is deliberately a seed, not an accepted definition. It may be too coarse because it can erase action labels, authority, probabilities, costs, provenance, or causal/diagnostic structure.

## Higher-order residual

This connection is not recoverable merely by saying the maps all concern "state" or "behavior."

The higher-order candidate is:

1. PD/ED supplies determinacy and result-sensitivity over admissible fibers.
2. T supplies the typed transition/control carrier.
3. ICC M0-M11 supplies the controller-specific decomposition of what must be preserved/learned.
4. Diagnostic equivalence shows terminal outcome quotients can be too coarse for reselection/repair.
5. Cumulative capability shows even episode-level behavioral success can be too coarse when later controller access is lost.
6. MultiObject supplies the method for testing whether these reductions survive independent routes.

Together they suggest that the central mathematical object may be a family of job-relative quotients over a typed controlled transition system, with determinacy, diagnosis, persistence, and capability reachability appearing as different projections or constraints on that family.

Classification: HIGHER_ORDER_CANDIDATE. Not promoted.

## Candidate unification spine

For a boundary b in state/history z, define a permitted continuation fiber Phi_J(z,b).

Determinacy:
Det_J(z,b) iff |Phi_J(z,b)|=1.

Sensitivity:
a coordinate c is J-sensitive when varying c changes the protected continuation quotient/result.

Behavioral equivalence:
z1 ~=_J z2 when all protected continuation behavior relevant to J is preserved.

Diagnostic refinement:
z1 ~=^diag_J z2 requires preservation of repair/reselection-relevant continuation structure, not merely terminal outcome.

Longitudinal preservation:
a contribution p learned at episode i is preserved at later state z_j only when a controller-realizable witness to p remains reachable/admissible, modulo licensed revision/retraction/supersession.

This produces a candidate dependency chain:

permitted fibers
-> determinacy/sensitivity
-> job-relative quotient
-> diagnostic refinement
-> controller selection/reselection
-> reachable execution
-> verified update
-> longitudinal preservation
-> re-entry.

## What collapses and what does not

Candidate collapse:
- Job-relative diagnostic equivalence is likely not an independent top-level map; it is a refinement problem inside job-relative behavioral quotient/controller-continuation mathematics.
- Cumulative autonomous research capability is likely a longitudinal/reachability extension of the same protected-continuation structure.
- Several M0-M11 regions are projections of one typed transition/control object rather than independent maps.
- ED appears reusable as a determinacy schema over multiple system fibers.

Not collapsed:
- MultiObject/map-discovery remains methodological machinery for testing the proposed reductions; no proof yet identifies it with the object-level transition system.
- Domain-specific algebras remain distinct from the system algebra unless a typed lift is established.
- Authority, provenance, evidence, probability/resource structure, and OPEN/INCOMPARABLE states cannot be quotient-collapsed without preservation proofs.
- No claim that PD itself has been reduced to transition-system mathematics is admitted.
