# Experiment 010 — IC28 Full Corpus Ingestion

Purpose: feed the actual current IC corpus into Take Four before asking it to improve IC26.

Input includes every immutable IC version, canonical IC26 state, ImprovementCore currentness surfaces, the Core System Mathematics corpus, tool-optimization corpus, goal-spine artifacts, and repository map/register artifacts.

The first pass has NO_SUBSTANTIVE_JOB. This preserves the blind-ingestion experiment: Take Four receives the corpus without being told what improvement to find. Later IC28 synthesis compares this autonomous frontier against directed PD/IC/tool passes.

This experiment proves corpus crossing and observability. It does not by itself prove semantic synthesis or strict gain.
